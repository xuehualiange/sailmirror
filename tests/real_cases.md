# 出海镜 SailMirror — 真实案例记录

## 案例 1：SHEIN 穆斯林礼拜毯误作装饰地毯（2020）

| 项目 | 内容 |
|------|------|
| **背景** | SHEIN 将带有宗教含义的穆斯林礼拜毯图案，作为普通家居装饰地毯在中东及全球市场上架 |
| **问题类型** | 文化合规 — 宗教符号 / 宗教物品商用 |
| **后果** | 一周内两次舆论翻车，社交媒体大量抵制，被迫紧急下架并公开道歉 |
| **出海镜检测点** | 文化合规 Agent 识别地毯图案中的宗教指向性元素，标注「极高风险：宗教物品不得作为装饰用途商用」 |
| **对应测试** | TC-002（十字架吊坠）、TC-006（佛像图案）同类逻辑验证 |

## 案例 2：2025 年 25-cv-656 案 — 600 家店铺 TRO 冻结

| 项目 | 内容 |
|------|------|
| **背景** | 2025 年 5 月，美国宾夕法尼亚州西区法院签发 TRO，因商品图和 Listing 合规疏漏，一次性冻结亚马逊、Temu、沃尔玛约 600 家店铺资金 |
| **问题类型** | 硬合规 — 绝对化用语、认证缺失、Listing 违规 |
| **后果** | 店铺资金冻结、链接下架、卖家现金流断裂 |
| **出海镜检测点** | 硬合规 Agent 扫描 Listing 中 "Best""#1""100%" 等绝对化用语，并提示 CE/FCC/CPSIA 等认证要求 |
| **对应测试** | TC-004（"Best" 绝对化用语）直接命中 FTC / 亚马逊广告政策风险 |

---

**结论：** 文化合规翻车损害品牌，硬合规失误冻结资金。出海镜双轨检测，在上新环节同时拦截两类风险。
